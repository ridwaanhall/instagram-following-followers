## Reporting back

End every task with a short report in chat, in this shape. One short line per
bullet, plain words, to the point. Leave out a heading that has no items.

```
add:
* ...

fix:
* ...

adjust:
* ...

delete:
* ...

remove:
* ...
```

- **add**: new features, pages, files, tests.
- **fix**: bugs and wrong behaviour that were corrected.
- **adjust**: changes to existing things (style, size, copy, config).
- **delete**: files deleted from the repo.
- **remove**: code, features or UI taken out without deleting a whole file.
